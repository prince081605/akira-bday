Put Akira's photos in this folder (for example 1.jpg, 2.jpg ... 6.jpg).
Use file names without spaces, e.g. tiny-hands.jpg.

Then open script.js and set the matching "src" in the photos list, for example:
  { src: "photos/1.jpg", caption: "Our little blessing", emoji: "👶" },

Tip: resize photos to about 1200px wide first so the page loads fast on phones.
